# Architecture

A static site: `index.html`, `css/`, `js/`, `data/`, `img/`, `fonts/`, `audio/`, `sw.js` and `manifest.webmanifest`. No backend and no build step. All paths are relative, so the app works at a domain root and in a subdirectory.

## Modules (ES modules, no globals except `js/vendor/`)

| File | Exports | Contract |
| --- | --- | --- |
| `js/deck.js` | `newSeed(cards, history)` | base36 seed from `crypto.getRandomValues`, redrawn until the card is not among the recent history |
| | `draw(seed, cards)` | deterministic `{card, reversed}` (reversed ≈ 30%) |
| | `loadHistory()` / `saveHistory(h)` | `localStorage`, wrapped in try/catch |
| `js/oracle.js` | `compose({seed, card, reversed, name, zodiac, company, industry, stage, lang, grammar, ui})` | `{parts: [{id, text}], quote}`; the last two parts are the punchline (always recommends a designer) and the call to action |
| | `INDUSTRIES`, `STAGES` | allowed form values, each with a grammar rule `branza_<id>` / `etap_<id>` |
| `js/app.js` | none | screens, form, `?s=` (seed) and `?lang=`, PL/EN switch, fan, tabs, menu, install flow, service worker registration and update handling |
| `js/fx.js` | background canvas, reveal effects, tilt, sparkles, title flicker | respects `prefers-reduced-motion` |
| `js/audio.js` | `start()`, `sfx(name)`, `toggleMute()` | starts after a user gesture, pauses in the background, caches the music offline |
| `js/share.js` | `shareImage(data)` | draws a 1080×1920 image on a canvas; the name never goes on the image, the company does |

## Data (schemas in `schema/`)

- `data/cards.json`: 78 cards, schema `schema/cards.schema.json`. Text fields are `{pl, en}`.
- `data/grammar.{pl,en}.json`: Tracery grammar. Required symbols: `origin`, `wezwanie`, `znaczenie`, `cta`, `puenta_identity|uxui|website|startup`, and one `branza_<industry>` and `etap_<stage>` rule per value (`omen` is injected by `oracle.js` from the zodiac data).
- `data/zodiac.{pl,en}.json`: 12 signs with `id`, `element`, name forms and `omens[]`.
- `data/ui.{pl,en}.json`: all interface strings. Text is never hard-coded in the JavaScript, except the Polish glyph list used to preload fonts.

## Updates without clearing the cache

- Modules and data are requested as `file?v=N` (`tools/bump_version.py` updates `N` in `index.html` and in the imports of `js/app.js`), so a reload never mixes new and old files.
- `sw.js` (generated by `tools/build_sw.py`) is network first with revalidation; the cache is only an offline fallback. A new worker takes over at once. The page reloads immediately on the intro screen or the form, and after the draw is finished otherwise.
- `.htaccess`: `no-cache` for pages, scripts, styles, data, images and fonts; music is cached for a day and gets a new file name when the track changes.

## Validation (scripts in `tools/`)

- `tools/validate_cards.py`: JSON Schema validation of `cards.json`.
- `tools/test_oracle.mjs`: every card × position × zodiac sign × industry × stage × language combination (7488 readings): no leftover `#`, no `undefined`, every reading has the punchline, the context paragraph sits right before it.
- `tools/smoke.cjs`: browser flow in PL and EN on a 390 px and a 320 px phone, plus regression checks for earlier bugs.
- `tools/update_test.cjs`: simulates a release and checks that users get the new version without clearing the cache, also from an old version.

## Server

Apache. See `.htaccess` for MIME types and cache headers. Deployment is `tools/deploy.sh` (SFTP, credentials kept outside the repository).
