# Spooooky Deck

Mroczna, pikselowa wyrocznia tarota dla firm. Wpisujesz imię, znak zodiaku i firmę, losujesz kartę z talii 78 kart, a wróżba zawsze kończy się wnioskiem, że firmie przyda się projektant.

Czyste pliki statyczne (HTML, CSS, JS), bez backendu i bez buildu. PWA, PL + EN.

Status: w budowie. Plan: [plan-aplikacji-tarot-dla-firm.md](plan-aplikacji-tarot-dla-firm.md).

Autor: [whosz.pl](https://whosz.pl)
