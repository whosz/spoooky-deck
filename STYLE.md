# Style

| Role | Colour |
| --- | --- |
| Background | `#0b0d17` |
| Surfaces | `#161a2a`, `#222842` |
| Borders | `#8a6a2e`, `#d8aa48` |
| Light (CTA, active) | `#ffb347` |
| Dread (reversed card) | `#b3243a` |
| Magic (sparks, offer link) | `#f4efe6` |
| Text | `#e8dcc0` |

Fonts (local): Old English Gothic Pixel for the title (OFL), Jacquard 12 and Olde Tome for headings and buttons, Geist Pixel for body text and labels. Always check the Polish letters ąęśćźżłóń.
Cards: 64×96 px art in a 16-colour palette without dithering, scaled by a whole number of device pixels, `image-rendering: pixelated`.
Suits: Wands `#ff8a2b`, Cups `#3fd0c9`, Swords `#7fa8d8`, Pentacles `#d8aa48`.
Title: gold metal with hard light bands per line, a dark outline, brown descenders on p and y, and a pixel shine sweeping from the bottom left to the top right.
